# Documentation

The documentation for this project is built into the frontend application.

To access it:
1. Deploy the application (see root README.md)
2. Navigate to the `/documentation` route in the dashboard

This directory also holds the images used by the root README:

- `architecture/diagram.svg`, the signal processing flow
- `ui/`, dashboard screens rendered from the application's own stylesheet and components, with sample data

The in-app documentation includes:
- Getting Started / Quick Start
- API Reference (ESAM, Channels, Logs)
- Features (Rules, Stateful Mode, External Actions, VIS, Descriptor Priority)
- Configuration reference (Lambda environment, DynamoDB, CloudWatch) and Authentication
- Monitoring and Troubleshooting
